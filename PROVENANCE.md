# Pretraining provenance

Written by `drfair.models.fetch_weights` (S0.4) and completed by hand where a source must be read
(plan D3). One row per checkpoint. Every claim names its source (model card, paper section or
code file), the URL and the access date; a third party's statement is recorded but is not a
verification.

Exposure categories, per evaluation set: *independent*, *exposed*, *unknown-web*,
*unknown-retinal*. Eligible for the primary backbone and the finalists: *independent* or
*unknown-web* for both BRSET and mBRSET.

## D3 checks of the retinal foundation models (2026-11-14)

One check per model, before the lock (register row "Backbone benchmark (descriptive)"). A model whose pretraining data cannot
be verified, or whose weights cannot be obtained, is excluded with the reason; a model exposed to BRSET is excluded
(study lead, 2026-11-14; DEVIATIONS.md #4). Eligibility as primary or finalist (plan D3) is a separate matter: these
models enter the descriptive benchmark only.
