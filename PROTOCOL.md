# drfair protocol

Implements `IMPLEMENTATION_PLAN.md` v4.2. This file, with `protocol.yaml`, `PROVENANCE.md`,
`DEVIATIONS.md` and `selections/`, is mirrored to the public protocol-only repository and locked
by the signed tag `protocol-v1` (plan D12). Numbers that the code uses live in `protocol.yaml`;
this file records decisions, sign-offs and governance.

## 1. Decisions register

A value that is still *proposed* or *deferred* at the lock is recorded as deferred, and every
decision that depends on it is reported as estimation only (plan §4). Nothing becomes approved
by default.

## 7. Data findings that shape the protocol

- Missingness of the core metadata (D2). In the B-DM primary population, at the patient level, logistic missingness models adjusted for age and sex gave, for missing diabetes duration, referable status: OR 0.9 (95% CI 0.678-1.194; p = 0.465); the Nikon camera: OR 4.561 (95% CI 1.977-10.524; p = 0.000375); for missing insulin, referable status: OR 0.695 (95% CI 0.531-0.912; p = 0.00855); the Nikon camera: OR 5.436 (95% CI 2.255-13.099; p = 0.000162).
